## ✨ Features

| Feature | Description |
|---|---|
| 📥 **Import** | JSON, Markdown, TXT via file drop, paste, or manual entry |
| 📤 **Export** | Download as JSON, Markdown, or PDF |
| 🔍 **Search** | Real-time full-text search with highlighted results |
| 💾 **Backup** | ZIP archive with all sessions + individual Markdown files |
| 🔄 **Restore** | Re-import from any backup ZIP or JSON |
| ✨ **Summarize** | Auto-generate summaries, key topics & word counts |
| ✏️ **Rename** | Rename any conversation |
| 📋 **Copy** | Copy individual messages to clipboard |
| ⌨️ **Shortcuts** | `Ctrl+K` to search, `Esc` to close modals |

## 🚀 Getting Started

### Option 1 — Use the Live App
Just open the live demo: **[http://incomparable-snickerdoodle-436526.netlify.app](http://incomparable-snickerdoodle-436526.netlify.app)**

### Option 2 — Run Locally
```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/convovault.git

# Open in browser — no server needed!
cd convovault
start index.html   # Windows
open index.html    # macOS
```

> 💡 It's a **single HTML file** — just open `index.html` in any browser. No npm, no build step, no backend.

## 🛠️ Tech Stack

- **Pure HTML + CSS + Vanilla JavaScript** — zero dependencies, zero build tools
- **[jsPDF](https://github.com/parallax/jsPDF)** — PDF export
- **[JSZip](https://stuk.github.io/jszip/)** — ZIP backup & restore
- **[Inter](https://fonts.google.com/specimen/Inter)** — Typography
- **localStorage** — All data stored locally in your browser

**100% local.** No data is ever sent to any server. Everything lives in your browser's `localStorage`. You own your data.
